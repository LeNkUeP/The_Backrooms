# The_Backrooms

This is a prototype for a backrooms-type procedural and infinite level generator. The generator has settings which influence the generation of the world like number of doors, minimal and maximal door width, holes in th ground, number of lights etc. While the player moves in a direction the game world automatically increases its size. An additional feature is that rooms are stored so when an old position is re-visited, the room can be fully recreated.
